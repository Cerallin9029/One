# Security and privacy

Lens does not execute instruction contents or make network requests. It follows file symlinks
and reports targets outside the project root. Default output contains local paths; `--show-text`
also includes instruction bodies. Do not attach private bodies, credentials or personal paths
to public issues. Terminal output JSON-escapes untrusted strings.

For a security concern, use GitHub private vulnerability reporting if enabled for this
repository. If unavailable, open an issue requesting a private reporting channel without
publishing sensitive details. This alpha has no promised response-time SLA.
